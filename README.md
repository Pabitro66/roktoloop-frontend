# Roktoloop Frontend

A responsive five-page frontend prototype for a blood-donation community in Bangladesh.

## Pages
- Home
- Find Donors
- Request Blood
- Become a Donor
- About

## Tech stack
- React + TypeScript
- Vite
- React Router
- Tailwind CSS
- Lucide React

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

Vite outputs the production build to `dist`. The project includes a Vercel rewrite configuration for client-side routing.

## Important
This is a frontend-only demonstration. Donor profiles are sample data, and the request/registration forms do not store or transmit information. Connect a secure backend and verified, consent-based donor data before real-world use.
